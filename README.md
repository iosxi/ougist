# ougist

画面の左右の端から指をすべらせると扇形にアイコンが開き、指を離した位置のものが実行される Android アプリ。

- 対応: Android 9 (API 28) 〜 最新 (targetSdk 36 / Android 16)
- 出来上がり: `build/ougist.apk`
- 要求する権限: **`VIBRATE` の 1 つだけ**

> このビルドは実機・エミュレータでの動作確認をしていない（作った環境に Android 端末が
> 繋がっていなかったため）。組み立てとパッケージの中身までは確認済み。

## できること

- 左端・右端からの内向きスワイプで扇が開く。**左と右で別々の中身**を登録できる。
- アイコンには **アプリ** と **端末の操作** のどちらも置ける。
  - 操作: 戻る / ホーム / 履歴 / 通知シェード / クイック設定 / シェードを閉じる /
    画面ロック / 電源メニュー / スクリーンショット / 分割画面 / 再生・一時停止 /
    ライト / ougist の設定
    （端末の Android のバージョンで使えないものは一覧に出ない）
- **列数を 1 か 2 から選べる。** 2 にすると**内側の円と外側の円**ができ、
  それぞれ別々にアイコンを登録できる。指を深く伸ばすほど外側の円が選ばれる。
- アイコンに指が移るたびに震える。強さは **7 段階**
  （なし / 弱 / 中 / 強 / 特強 / 激強 / 最強）。
- 扇の中心近くまで指を戻してから離すと、何も実行せずに閉じる。
- 1 つの円につき 12 個まで（2 列なら片側 24 個まで）。
  フォルダ、日時表示、バッテリー表示、下端からのスワイプは無い。

## 入れかた

1. `build/ougist.apk` を端末に移して開き、インストールする（提供元不明のアプリの許可が要る）。
2. ougist を起動し、**「設定を開く」**からアクセシビリティ設定へ。
   「インストール済みのアプリ」→ **ougist** を選んで有効にする。
3. 左右の端から内側へスワイプすると扇が開く。

> **スイッチが灰色で押せないとき**（Android 13 以降で、ストア以外から入れたアプリの制限）
> 設定 → アプリ → ougist → 右上の ⋮ → **「制限された設定を許可」** を押してから、もう一度 2 をやり直す。

初回は左右ともに「戻る / ホーム / 履歴 / 通知シェード（右はクイック設定）」が入っているので、
入れてすぐ試せる。中身は設定画面の「左のアイコンを編集 / 右のアイコンを編集」から差し替える。

## 権限について

要求している権限は `VIBRATE` だけ。ほかは次のやり方で避けている。

| ふつう要る権限 | ougist がそれを避けた方法 |
| --- | --- |
| `SYSTEM_ALERT_WINDOW`（他のアプリの上に表示） | アクセシビリティサービスから `TYPE_ACCESSIBILITY_OVERLAY` の窓を出すので不要 |
| `QUERY_ALL_PACKAGES`（全アプリの列挙） | マニフェストの `<queries>` でランチャーに出るアプリだけを見る |
| `FOREGROUND_SERVICE` ほか | 常駐はアクセシビリティサービス自体が担うので不要。常駐通知も出ない |
| `RECEIVE_BOOT_COMPLETED` | アクセシビリティサービスは再起動後に自動で戻る |
| `CAMERA`（ライト） | `CameraManager.setTorchMode` は権限不要 |

アクセシビリティサービスの設定（`app/src/main/res/xml/accessibility_service_config.xml`）では
`canRetrieveWindowContent="false"` を宣言し、購読するイベントの種類も宣言していない。
つまり**画面の内容は読み取らない**。使っているのは「端に窓を置く」ことと
「戻る・ホームなどのグローバル操作を実行する」ことだけ。

## 設定の項目

| 項目 | 意味 |
| --- | --- |
| 列数 | 円をいくつ並べるか。1 なら今までどおり、2 なら内側と外側の 2 重になる |
| 内側の円までの距離 | 扇が開く始点から**内側の円**までの距離。画面に収まらない値は自動で縮む |
| 内側から外側までの距離 | **内側の円から外側の円まで**の距離（2 列のときだけ出る） |
| アイコンの大きさ | 扇に並ぶアイコンの直径 |
| 扇の広がり | 何度ぶんの弧に並べるか（60〜180°） |
| 背景を暗くする | 扇が出ている間、後ろを暗くする度合い |
| 名前を表示する | 選んでいるアイコンの名前を横に出す |
| 反応する端の幅 | 端の何 dp を「スワイプの受け口」にするか。ここに触れた指は下のアプリには届かない |
| 上の余白 / 下の余白 | 受け口を画面の上・下から何 % 空けるか。どちらも 0 % なら画面の高さいっぱい |
| 反応し始める距離 | 内側へ何 dp 動かしたら扇を開くか |
| 触覚フィードバック | 震えの強さ。7 段階。選ぶとその場で試せる |

「反応する端の幅」を広くするほど扇は出しやすくなるが、そのぶん端のスワイプ
（アプリ内の横スワイプなど）が ougist に吸われる。14dp 前後から始めて、好みで調整するのがよい。

### 震えが弱いとき

「弱 / 中 / 強」は端末が用意している定義済みの効果
（`EFFECT_TICK` / `EFFECT_CLICK` / `EFFECT_HEAVY_CLICK`）をそのまま鳴らしている。
これは端末ごとにチューニングされていて感触は良いが、一番強い `EFFECT_HEAVY_CLICK` でも
頭打ちになる。そこで **「特強」以上は定義済みを離れ、振幅を最大にして震える時間を延ばす**
（35 / 55 / 80 ミリ秒）。

もう 1 つ、Android 13 以降は震えの「用途」ごとに強さが別々に調整される。
「弱 / 中 / 強」は*触れた合図*（`USAGE_TOUCH`）として鳴らすので、端末の
「タッチ時の触覚フィードバック」の設定に従って弱められる。
**「特強」以上は*アクセシビリティの合図*（`USAGE_ACCESSIBILITY`）として鳴らす**ので、
そこで頭を押さえられない。ougist はアクセシビリティサービスそのものなので、
用途としても外れていない。

それでも弱いときは、端末の 設定 → 音とバイブレーション → 振動の強さ を確認する。
ここが低いと、どの段を選んでも全体が弱くなる。

### ジェスチャナビゲーションとの兼ね合い

Android 10 以降の「ジェスチャナビゲーション」を使っていると、画面の端の横スワイプは
システムの「戻る」ジェスチャとぶつかる。ougist は受け口の範囲について
`View.setSystemGestureExclusionRects`（そこを戻るジェスチャに使わないでほしい、という申告）を
出しているが、この申告は**画面の端から 200dp ぶんまでしか聞いてもらえない**決まりで、
どこまで効くかは端末の実装にもよる。

扇がうまく出ない・出かけて消えるときは、次のどれかを試すとよい。

- 「上の余白」を大きくして、受け口を画面の**下寄り**に集める（申告が効きやすい範囲）
- 「反応し始める距離」を小さくして、システムが戻ると判断する前に扇を開かせる
- 3 ボタンナビゲーションに切り替える（この場合は競合しない）

## 作りなおす

```bash
bash tools/build.sh          # build/ougist.apk ができる
VERSION_CODE=3 VERSION_NAME=1.1.1 bash tools/build.sh
```

Gradle も外部ライブラリも使わず、Android SDK の道具（aapt2 / d8 / zipalign / apksigner）と
JDK だけで組み立てる。必要なもの:

- JDK 17 以上
- Android SDK（`build-tools` と `platforms` が 1 つ以上入っていること。`ANDROID_HOME` で場所を指定できる）

`keystore/ougist.jks` は最初のビルドで自動生成される署名鍵。**消さないこと**
— 消すと署名が変わり、上書きインストールができなくなる（アンインストールが必要になる）。
人に渡すものでもない。

Android Studio で開きたい場合は、このフォルダをそのまま開けば `settings.gradle` /
`app/build.gradle` が使われる（`namespace` は Gradle 側で与えるので、
`AndroidManifest.xml` に `package` 属性は書いていない）。

## 中身

```
app/src/main/java/io/ougist/
  OugistService.java     本体。端の窓を出し、扇を出し、選ばれたものを実行する
  EdgeView.java          端に置く見えない帯。スワイプの始まりを見る
  FanView.java           扇そのもの。描画と、指の位置からどれを選んでいるかの判定
  Actions.java           登録できる「端末の操作」の一覧
  Slot.java / Config.java  登録内容と設定 (SharedPreferences に JSON 1 本)
  IconCache.java         アイコンを描く大きさのビットマップにしておく
  Haptics.java           震えの作りかた。段ごとの効果と、どの用途で鳴らすか
  MainActivity.java      設定画面 (扇の見本つき)
  SlotListActivity.java  片側ぶんの一覧。並べ替えと割り当て
  AppPickerActivity.java アプリを選ぶ画面
  Ui.java                画面を組み立てる小道具
```
